#### Callout 지원리스트  
  
Callout 문법이 좋은 이유는 위의 문법에서 `[!note]` 부분을 다음과 같은 키워드로 바꿔주면 알맞은 아이콘에 색상이 다른 Callout 상자가 생성된다는 것입니다. 한번씩 시도해보세요! (같은 줄에 있는 단어들은 같은 아이콘 유사어들입니다.)  
  
```md  
- [!note]  
- [!abstract], [!summary], [!tldr]  
- [!info]  
- [!todo]  
- [!tip], [!hint], [!important]  
- [!success], [!check], [!done]  
- [!question], [!help], [!faq]  
- [!warning], [!caution], [!attention]  
- [!failure], [!fail], [!missing]  
- [!danger], [!error]  
- [!bug]  
- [!example]  
- [!quote], [!cite]  
```  
  
> [!note] 노트  
> 기본적인 노트 형식의 콜아웃입니다. 중요한 정보를 강조할 때 사용합니다.  

> [!abstract] 요약
> 문서나 섹션의 핵심 내용을 요약할 때 사용합니다.
  
> [!summary] 요약  
> abstract와 동일한 스타일이 적용됩니다. 내용을 간략하게 정리할 때 좋습니다.  
> 하이
> 하이하이
> 하이하이 하이
  
> [!tldr] 요약  
> "Too Long; Didn't Read"의 약자로, 긴 내용을 간결하게 요약할 때 사용합니다.  
  
> [!info] 정보  
> 추가적인 정보나 참고 사항을 제공할 때 사용합니다.  
  
> [!todo] 할 일  
> 해야 할 작업이나 단계를 나열할 때 유용합니다.  
  
> [!tip] 팁  
> 유용한 조언이나 더 나은 방법을 제안할 때 사용합니다.  
  
> [!hint] 힌트  
> 문제 해결에 도움이 되는 힌트를 제공할 때 사용합니다.  
  
> [!important] 중요  
> 특별히 중요한 정보를 강조할 때 사용합니다.  
  
> [!success] 성공  
> 성공적으로 완료된 작업이나 긍정적인 결과를 표시할 때 사용합니다.  
  
> [!check] 확인  
> 완료된 항목이나 확인된 정보를 표시할 때 사용합니다.  
  
> [!done] 완료  
> 완료된 작업이나 달성한 목표를 표시할 때 사용합니다.  
  
> [!question] 질문  
> 질문이나 의문점을 제시할 때 사용합니다.  
  
> [!help] 도움말  
> 도움이 필요한 부분이나 지원 정보를 표시할 때 사용합니다.  
  
> [!faq] 자주 묻는 질문  
> 자주 묻는 질문과 그에 대한 답변을 제공할 때 사용합니다.  
  
> [!warning] 경고  
> 주의가 필요한 사항이나 잠재적인 문제점을 경고할 때 사용합니다.  
  
> [!caution] 주의  
> 조심해야 할 사항이나 위험 요소를 안내할 때 사용합니다.  
  
> [!attention] 주의  
> 특별한 주의가 필요한 부분을 강조할 때 사용합니다.  
  
> [!failure] 실패  
> 실패한 작업이나 오류가 발생한 부분을 표시할 때 사용합니다.  
  
> [!fail] 실패  
> 실패 상황이나 문제점을 명시할 때 사용합니다.  
  
> [!missing] 누락  
> 누락된 정보나 요소를 표시할 때 사용합니다.  
  
> [!danger] 위험  
> 심각한 위험이나 주의사항을 경고할 때 사용합니다.  
  
> [!error] 오류  
> 오류 메시지나 문제 상황을 설명할 때 사용합니다.  
  
> [!bug] 버그  
> 알려진 버그나 기술적 문제를 설명할 때 사용합니다.  
  
> [!example] 예시  
> 개념이나 기능의 구체적인 예시를 제공할 때 사용합니다.  
  
> [!quote] 인용
> 다른 출처에서 인용한 내용을 표시할 때 사용합니다.  
  
> [!cite] 인용
> 인용문이나 참고 자료를 표시할 때 사용합니다.
